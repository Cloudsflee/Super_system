## 3. 已修正的失效默认值与边界

- MCP Gateway 的 health、上游 Client 和下游 Server 不再硬编码 `1.8.0`，统一读取 `AIWS_VERSION`；集成测试同时断言 health 和 MCP server version 为 `2.0.0`。
- `docker/verify-refresh.Dockerfile` 的独立构建默认镜像由 `aiws-verify:1.7.0` 修正为 `aiws-verify:2.0.0`。
- MiniSearch 构建、规范字段、CJK 分词、序列化、恢复和查询从 API 收敛到 `@aiws/system-context`；API 仅负责 CAS 文本读取和数据卷索引文件持久化。根包的重复 `minisearch` 依赖已删除。
- 密钥节点不进入全文索引，涉及密钥节点的关系标题也不会旁路写入其他节点索引。
- 普通成员的全局地图只投影系统根和其有权访问的 Project；Owner 保留全局管理视图，但 Project 内 AI 不因此获得额外权限。
- 关系在生成 Markdown、全文索引与 API 响应前按调用者作用域过滤，跨 Project 正文仍要求有效 Exchange Grant，系统根不会泄露无权 Project 的关系标题。
- 关系快照纳入节点投影输入哈希，边变化会生成新的不可变文档版本；`source_record_hash` 仅标识源记录，`source_hash` 标识包含关系快照的完整文档输入。
- policy、browser state 和请求 anchor 在 state 事务内按最新 ACL 重新校验，避免并发权限变更后沿用过期授权结果。
- Release 验收直接复用生产 `contextIndexableNodes` 与 `contextSearchIndexSnapshotHash`，不再维护一套可能漂移的索引排序算法。
