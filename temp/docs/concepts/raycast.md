# 产品研究：Raycast

> 对应搜索角度：**行业产品与商业案例**

## 一、摘要

Raycast 是 macOS 上的键盘优先启动器（launcher），已经从"Alfred 替代品"演化为"超级个体的统一入口"——整合 AI 命令、Quicklinks、剪贴板历史、窗口管理、扩展商店，以及对 GitHub / Linear / Notion / Slack / Calendar 的深度集成。

## 三、为何与本毕设高度相关

- **主旨 1（AI 工作流透明化）**：Raycast 的"AI Commands / Presets"模式把"提示词 + 触发条件 + 输出目标"结构化——AI 操作变成可审计的"工作流"。
- **主旨 3（多模态展示）**：同一意图（"翻译"、"总结"、"重写"）可在任意输入框中触发——"模态"被消解为"上下文 + 触发器"。
- **主旨 5（行为资产化）**：用户自定义的 Presets / Quicklinks / Snippets 就是"老成员的行为资产"。
- **主旨 7（去形式化 PM）**：把 PM 工具（Linear）的快捷操作放到 Raycast，绕过 PM 工具的形式化 UI。

## 四、对毕设的启示

1. **"入口层"是常被忽视的关键层**——很多工具只做了"功能"但没做"如何 2 秒内进入这个功能"。Raycast 的范式值得借鉴。
2. **预设（Presets）= Prompt 资产化**——把"AI 提示词 + 触发场景 + 输出形式"做成可复用单元。
3. **跨应用集成 = 减少切换成本**——一个 `⌘ Space` 处理 Linear、GitHub、Notion 的统一查询——这就是"超级个体"想要的效率。
4. **免费 + Pro 双层定价是开源精神的商业版**——Pro 资助开发；免费层保证基本可用。
