# 方法论研究：Building a Second Brain（BASB / 第二大脑）

> 对应搜索角度：**设计哲学与专注机制** / **学术理论与综述**

## 一、摘要

"Building a Second Brain"（BASB，第二大脑）是 Tiago Forte 提出的 PKM 方法论，以 **CODE** 四步法（Capture / Organize / Distill / Express）为核心。它与 Zettelkasten 并列为当代 PKM 两大主流方法论，但侧重不同——Zettelkasten 偏学术 / 思想，BASB 偏创意 / 项目。

## 三、CODE 四步法详解

| 步骤 | 描述 | 工具示例 |
|------|------|----------|
| **Capture** | 把灵感、引用、笔记"抓"到系统中，不求完整 | 浏览器扩展、语音转文字、微信收藏 |
| **Organize** | 用 PARA 等分类法整理 | Notion / Obsidian / Logseq |
| **Distill** | 提炼核心——标注、总结、渐进式摘要（Progressive Summarization） | 高亮、批注、自己的话重述 |
| **Express** | 输出——产出文章、产品、决策 | 写作、播客、决策 |

## 四、为何与本毕设高度相关

- **主旨 5（行为资产化）**：BASB 是"行为资产化"的另一种范式——比 Zettelkasten 更"项目导向"，更适合"超级个体"实际产出。
- **主旨 7（去形式化 PM）**：PARA 分类法比传统"文件夹"更轻量——它是"按用途"分类而非"按主题"。
- **主旨 3（多模态展示）**：BASB 的"渐进式摘要"提示同一份资产可有"原文 / 标注 / 总结 / 输出"四种呈现形态。

## 五、对毕设的启示

1. **PKM 方法论不止 Zettelkasten**——毕设应当支持多种方法论，让用户选择。
2. **PARA 比文件夹更优**——按"项目 / 领域 / 资源 / 归档"分类，更符合"超级个体"的工作流。
3. **渐进式摘要（Progressive Summarization）是低成本高价值的特性**——自动给笔记分层（原文 → 标注 → 总结 → 行动项）。
4. **与 Zettelkasten 互补**：用 Zettelkasten 做"思想资产"，用 BASB 做"项目资产"——毕设若要支持两种工作流，可考虑把它们统一在"块"层。
