# 产品研究：Heptabase

> 对应搜索角度：**行业产品与商业案例** / **设计哲学与专注机制**

## 一、摘要

Heptabase 是一款"视觉化思考"工具，组合了卡片、白板、知识图谱。它面向"超级个体"——尤其重视视觉空间感的研究者、设计师、产品经理——把"卡片"作为原子，把"白板"作为画布，把"知识图谱"作为涌现视图。

## 三、为何与本毕设高度相关

- **主旨 3（多模态展示）**：Heptabase 是"视图 = 块结构 + 空间布局"的范本。同一份卡片可在白板 / 时间线 / 知识图谱中切换。
- **主旨 4（轻量化与去依赖）**：Super Individual 计划强调 local-first + 端到端加密——商业产品也能做到自托管级数据主权。
- **主旨 5（行为资产化）**：把"思考过程"沉淀为可回放的白板，新成员可"看见"老成员的工作流。
- **"超级个体"作为产品定位词**：Heptabase 直接使用 "Super Individual" 命名定价档，是毕设标题的**商业产品级对应物**。

## 四、对毕设的启示

1. **"超级个体"是有付费意愿的市场**——Heptabase 把这个概念变现了。
2. **可视化不是噱头，是结构**——白板 / 卡片 / Graph 三视图必须共享"块"作为底层数据。
3. **区域链接是杀手特性**——Heptabase 允许链接"空白处"而非仅卡片，这一类"反直觉"的设计往往就是产品差异点。
4. **AI 集成应以"内容理解"为中心**——Heptabase AI 不是 chatbot，是"语义搜索 + 自动卡片化"——把 AI 嵌入既有数据流。
