# 方法论研究：Shape Up（Basecamp）

> 对应搜索角度：**设计哲学与专注机制** / **行业产品与商业案例**

## 一、摘要

Shape Up 是 Basecamp（前 37signals）Ryan Singer 于 2019 年提出的产品开发方法论，著有《Shape Up: Stop Running in Circles and Ship Work that Matters》。它的核心是用 **Fixed time + Variable scope** 替代传统的"估算驱动"流程。

## 三、为何与本毕设高度相关

- **主旨 7（去形式化 PM）**：Shape Up 是"去形式化 PM"的**最系统化方法论**——它直接砍掉 velocity 报表、story point、daily standup 等形式。
- **主旨 2（贡献量化）**：Hill Chart 替代 velocity——贡献按"未知 → 已知"的位置度量，而非按工时。
- **主旨 5（行为资产化）**：每个 cycle 结束都"shaping → building → cooldown"——沉淀为可复用的工作循环。

## 四、对毕设的启示

1. **6 周 cycle 是合理的毕设周期**——毕设的开发节奏可对齐 Shape Up 的 cycle。
2. **Hill Chart 比 burndown chart 更诚实**——毕设若需展示进度，应选 Hill Chart。
3. **Appetite 而非 Estimate**——毕设的功能取舍应当基于"投入多少时间"而非"需要多少时间"。
4. **Cooldown = 缓冲**——毕设最后 1–2 周应留作"复盘 + 文档 + 答辩准备"，而非新功能。
